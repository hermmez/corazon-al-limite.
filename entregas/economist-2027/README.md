# Entrega para reproducción móvil

Mismo episodio de 70,000 segundos y 2100 fotogramas, 1080 × 1920 a 30 fps. Copia compatible con reproducción H.264 High nivel 4.0, YUV 4:2:0 de 8 bits y AAC-LC, con `faststart` para iniciar la reproducción por HTTPS sin descargar todo el archivo.

Se conserva la narración y no se altera la velocidad. El original permanece en la entrega local. Esta copia ocupa 27,845,012 bytes. Se preparó para compatibilidad móvil; no se probó en un dispositivo iPhone físico.
